# АИС ФГБУ Абаканская ЛСЭ

Каталог нового самостоятельного проекта: Django backend и Vue frontend в одном репозитории внутри `E:/VLSE`.

Текущий этап — согласование [спецификации системы](docs/specification.md), [ролевой модели](docs/access-control.md) и [начального состава, справочников и таблиц](docs/initial-data-and-tables.md). Рабочее приложение, база данных и перенос кода пока не создавались. Git ещё не инициализирован; удалённый репозиторий и публикация не создавались.

Планируемая структура: `backend/`, `frontend/`, `infra/`, `docs/`. Исходные проекты `../web-vue`, `../labalse` и `../labalse_front` сохраняются без переноса и удаления.

Согласованный путь сначала проверяется в [локальном кликабельном макете](../web-vue/docs/mockups/expertise-workflow-v1/prototype/index.html). Его действия учебные и не заменяют серверный учёт.
