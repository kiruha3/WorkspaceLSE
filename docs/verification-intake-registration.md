# Проверка вертикали приёмки и назначения — 28.10.2026

## Автоматические проверки

- Backend: 98 тестов прошли на PostgreSQL, включая реальные HTTP-сессии делопроизводителя, начальника и эксперта, отказ стажёру, конкурентный номер и конкурентное назначение, повтор запроса, области доступа и сохранение прежних файлов.
- Frontend: 56 тестов прошли; TypeScript и production build успешны. Проверены multipart, стабильный ключ повтора, отсутствие `randomUUID` при внешнем HTTP, сохранение черновика при 403/409, поздние ответы, версии предпросмотра и возврат к фильтрам.
- Рабочие миграции применены; `makemigrations --check --dry-run` не выявил изменений. Один Vite на `0.0.0.0:5173`, Django и PostgreSQL на loopback; цепочки launcher/child Python — один сервер, не несколько слушателей.

Тестовые PostgreSQL suites запускаются последовательно: два одновременных pytest с одним test database конфликтуют при создании/удалении. Наблюдавшиеся при ошибке контроллера timeouts не маскировались изменением продукта; повторный последовательный gate прошёл. Рабочая БД не удалялась.
