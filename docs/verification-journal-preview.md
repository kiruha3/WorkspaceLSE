# Проверка предпросмотра переноса журнала

Общая цель — основной журнал в Django, полный рабочий процесс и серверный отчёт 15.1 — остаётся незавершённой. Предпросмотр является подготовкой исторического переноса, не заменяет его и не создаёт рабочие экспертизы.

## Чтение и нормализация

Первый прогон новых проверок остановился на отсутствующих модулях. После минимальных контрактных заглушек получены 62 падающих проверки отсутствующего чтения/нормализации/CLI; ошибочная тестовая фикстура счётчика SQL получила явный доступ к тестовой БД, чтобы действительно проверять ноль запросов. После реализации 61 проверка прошла, одна выявила некорректный порядок ячеек в созданном тестовом OOXML: J оказался после P, библиотека не могла прочитать оставшиеся колонки. Диагностика raw на границе читателя подтвердила причину, исправлен порядок именно фикстуры, утверждения сохранены. Затем прошли62 проверки.

Ещё три проверки сначала воспроизвели пропуск предупреждения о формуле без кэша, падение всей операции на 5000-значном номере и принятие Excel serial110000 за дату 2201 года. Исправлены конкретные границы: неизвестный кэш не заменяется числом, длинный номер становится ошибкой своей строки, для числовых дат проверяется тот же диапазон годов. Расширенный прогон: **65 из65**, Django check без замечаний, дрейфа миграций нет. Общий серверный прогон выполняется перед закрытием первой части.

Чтение XLSX выполняется openpyxl3.1.5 в read-only режиме, CSV — стандартной библиотекой. Добавлен один Python-пакет и его зависимость et-xmlfile2.0.0, lock обновлён. Источник не сохраняется обратно, дополнительные службы не запускаются. CLI по умолчанию выводит только метаданные/сводку, не тексты дел; подробные строки требуют явного `--include-rows`.

## Проверка локального источника

Локальная копия первого листа от26.10.2026 прочитана независимо библиотекой таблиц и новым CLI. Оба способа нашли **466 регистраций**. SHA-256 до и после: `012e78fa9e15b2a40b29a854ab8edae83c463e0b121d2f48f434ce785c7a07ae`. CLI не обращается к БД и не выводит содержимое дел без отдельного флага. Остальные листы не использовались.

В этой копии411 completed,34 in_progress,4 suspended и17 without_execution. Новый разбор показывает10 строк с ошибками и7 строк с предупреждениями; это диагностика старой копии, не утверждение о состоянии исправленной позднее Google-таблицы. Известные значения не исчезают из строки из-за ошибки в другом поле. Кэшированные формулы отмечены отдельно, без пересчёта и без объявления их достоверной новой длительностью производства.

## Оставшаяся работа

Сохранение снимков, API, права и Vue-предпросмотр ещё не реализованы; общий итоговый review следует после них. Актуальный источник для первого реального переноса уточняется у владельца. Затем требуются явные сопоставления и историческое применение в основные сущности, поддержка недостающих исторических подтверждений и Python-расчёт 15.1. Нет кнопки или команды с фиктивным успехом применения.
