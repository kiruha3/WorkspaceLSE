# Предпросмотр переноса журнала

Модуль принимает первый лист XLSX либо UTF-8 CSV и сохраняет неизменяемый снимок исходного файла, ячеек и результата разбора. Он не создаёт рабочие экспертизы, сотрудников, квалификации, окончания или выдачи. `apply_available` всегда false; endpoint применения отсутствует. Историческое применение и серверный15.1 остаются следующими частями общей цели.

Снимок содержит SHA-256 исходных байтов, имя первого листа, систему дат1900/1904, версию разбора, инициатора, время и общую сводку. Каждая строка сохраняет raw A..AB, формулы, неизвестные колонки, нормализованные факты и конкретные замечания. Пустое количество не заменяется нулём; отметка «СНДЗ» в причине не меняет вид результата. Номер в скобках не исправляет текущий. Поздние уточнения источника создают новый снимок, не перезаписывают прежний.

## Права

Чтение метаданных, строк и оригинала требует отдельного `imports.results.view` в области учреждения. Создание дополнительно требует `imports.preview`. Обычное чтение экспертиз, документов или кадровых данных не открывает снимки. Источник может включать разные и нераспознанные отделы, поэтому частичная область по отделам здесь ещё не обещается. Она проектируется вместе с подтверждённым сопоставлением и применением.

Новые права входят только в новые начальные шаблоны: делопроизводитель получает создание/чтение, руководитель учреждения — чтение. Существующие реальные роли автоматически не изменяются. Для учебного делопроизводителя есть явный `infra/local.py workflow-demo --enable-import-preview`: только два новых права, без восстановления отозванных прочих; роль с неучебным участником не расширяется.

## API

Префикс `/api/v1`. Создание: multipart `file,reason` и непустой Idempotency-Key до100 символов. Ответ201 `{event:{id},batch:BatchDTO}`. Receipt хранит только event/batch IDs. Повтор с теми же байтами, именем и нормализованным основанием возвращает прежний снимок; иное тело с тем же ключом —409. Нынешние права проверяются до повтора и перед ответом. Ошибка откатывает строки, снимок, аудит и receipt, удаляя только новый собственный файл.

| Путь | Результат |
| --- | --- |
| POST `/imports/preview/` | Сохранить результат проверки нового источника |
| GET `/imports/?page` | Постраничный журнал снимков |
| GET `/imports/{id}/` | Метаданные и общая сводка снимка |
| GET `/imports/{id}/rows/?search&severity&state&page` | Исходные строки и факты, фильтры до count и pagination |
| GET `/imports/{id}/source/` | Авторизованный исходный файл как attachment |

`severity`: error/warning/info; `state`: completed/without_execution/in_progress/suspended/unknown. Поиск включает номер, эксперта, описание дела и орган. Summary относится ко всем строкам снимка, не только открытой странице. Бизнес-таблицы не изменяются.

BatchDTO: id, source_name, source_kind, date_system, source_sha256, sheet_name, parser_version, created_at, actor либо null, row_count, summary, version, apply_available:false, source_url. RowDTO: id, source_row, raw, formulas, extra, facts, diagnostics, normalization_complete. «Разобрано» означает отсутствие ошибок нормализации, а не полноту для отчёта или разрешение применять сведения.

Лимиты:20MiB источника,64MiB раскрытого XLSX,1000ZIP-частей,10003физических строки и128колонок. Проверяются фактические координаты: устаревшее поле размеров XLSX не обрезает строки. Числовые значения C/P сохраняются до преобразования стилем даты, включая кэш формул; несуществующий день60 системы1900 остаётся ошибкой. Другие листы не разбираются. Формулы в B:X без кэша не теряют строку; A/Z/AA/AB без деловых сведений остаются шаблоном. Формулы не исполняются; кэш и его отсутствие отмечаются отдельно. В исходник ничего не сохраняется обратно. Для read-only CLI: `manage.py preview_journal PATH`; полный вывод строк требует отдельного `--include-rows` и не предназначен для общих логов.

Файловая граница рассчитана на используемое локальное FileSystemStorage. Файл создаётся исключительно как новый; при перехватываемой ошибке записи/закрытия удаляется только собственный частичный файл, существующий путь не перезаписывается и не удаляется. Подключение удалённого storage требует отдельной реализации этой границы. Восстановление согласованности БД и файлов после жёсткого завершения процесса пока не реализовано; транзакция БД не делает файловую систему транзакционной.

## Интерфейс и оставшаяся работа

### Настроенный источник Google

Сервер умеет читать значения выбранного листа через CSV export, не записывая в таблицу и не меняя доступ. Настройка: `backend/.venv/Scripts/python.exe infra/local.py journal-source <spreadsheet_id> <gid> <точное_название_листа>`, затем перезапуск одного Django. Конфигурация хранится в игнорируемом runtime-файле вместе с существующей локальной конфигурацией; учётные данные не выводятся и не изменяются. Ненастроенный источник не наследуется из случайных переменных окружения локального запуска.

`GET /api/v1/imports/google-source/` требует imports.results.view и возвращает configured:false либо configured:true,spreadsheet_id,gid,sheet_name,label,url. `POST /api/v1/imports/google-preview/` требует оба права предпросмотра, reason,spreadsheet_id,gid и Idempotency-Key. Источник должен совпадать с серверной настройкой. Повтор успешной команды возвращает тот же снимок до нового обращения к Google; иное основание либо изменившаяся конфигурация дают409. Отзыв прав проверяется и при повторе.

Сохраняются source_origin=google_csv,origin_url,source_observed_at; у прежних файлов — upload,пустойURL,null. Это снимок значений CSV, не формул и не всей структуры исходной Google-книги. Читается только настроенный gid. Timeout20с, предел20MiB, только HTTPS Google-export/Googleusercontent redirects, без cookies и авторизации. Недоступный/закрытый источник и HTML-вход возвращают управляемую ошибку без частичного снимка. Автоматическое опубликование или OAuth-подключение не выполняется.

Серверная часть Google реализуется в плане `2026-10-28-journal-application`; кнопка Vue и настоящая сквозная проверка будут приняты вместе с его интерфейсом. Наличие нового endpoint не означает уже выполненный перенос в рабочие Expertise.

Vue `/imports` и `/imports/:id` включаются только по `journal_import_preview` и правам. Предусмотрены загрузка, список, фильтры и сопоставление raw→facts→diagnostics. Применение, разрешение исторических неоднозначностей и отчётность не выдаются за выполненные действия. Сквозная проверка в браузере выполнена на трёх учебных строках, реальные рабочие записи не изменились. [Результаты проверки и итоговое ревью](verification-journal-preview.md).
