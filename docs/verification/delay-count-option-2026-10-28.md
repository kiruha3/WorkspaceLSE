## Принятые решения

1. Выбор для конкретного расчёта, не настройка учреждения. Режимprimary нужно снова выбрать при новом открытии страницы; all — подтверждённый владельцем default.
2. Полный список с одной известной группой однозначен без индивидуального признака основной причины. Для нескольких возможных групп неопределённость не скрывается нулём.
3. Управление годовыми планами — отдельный следующий срез. Его черновики сохранены, но приложение/схема планов в этом изменении не создавались и не объявлены готовыми.
