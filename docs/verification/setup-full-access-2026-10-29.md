# Полный доступ setup ·29.10.2026

Прямой ответ владельца на вопрос о `expertise.closed.correct`: **«Дай ему все права»**. Это новое разрешение отменяет прежнее ограничение «добавить только reports.plans.manage» для последующего изменения доступа setup, но не разрешает менять права других сотрудников.

Через действующий HTTP API, от авторизованного setup:

- получен текущий каталог61права, у каждого поддерживается область `institution`;
- создана отдельная роль **«Полный доступ · setup»**, ID `b96ef6ef-de05-4339-840c-ae74bd3d0710`;
- роль назначена только сотруднику, связанному с setup, без ограничения по отделам;
- повторное чтение `/me/` подтверждает все61кода, для каждого есть правило `institution` с пределом `institution`;
- все старые назначения ролей и общие роли/их разрешения сравнены до/после и не изменились. Ранее выданные роли не удалялись.

Пароль, признаки Django superuser/staff, учётки других сотрудников, экспертизы и отчётные факты не изменялись. «Все права» означает текущий каталог действий АИС, не права ОС/PostgreSQL и не автоматическую выдачу будущих неизвестных разрешений. Наличие разрешения не означает, что все будущие функции уже реализованы. В интерфейсе нужно обновить страницу.

Исполнение и проверка: `.runtime/enable-setup-all.py`; результат без секретов `.runtime/setup-full-access-20261029.json`. Изменения штатно записаны в аудит создания роли/назначения. Данные не правились напрямуюSQL.
