# Выбор документов по названию — 29.10.2026

## Результат

Общий DocumentPicker заменяет ручной ввод ID в подтверждении исторической
работы, сведениях дела, предыдущих заключениях, подтверждениях сроков,
годовом плане и приложениях к письмам. Основной документ результата
использует тот же компонент. Поиск по названию или имени файла,
постраничный список, предпросмотр выбранного и «Добавить новый» рядом.
Выдача материалов сохраняет свой контекстный API поиска по названию;
её переключатель заменён такими же кнопками без изменения состава комплекта.

GET `/api/v1/documents/?search=...&kind=resolution,decision&page=N`
возвращает прежнюю структуру документа внутри стандартной страницы.
Существующая политика `can_document` применяется до выдачи и подсчёта.
Права не выдаются автоматически. Запрос поиска не записывает документы
или события аудита. Схема БД, команды родителей, версии и ключи повторов
сохраняются. Две прежние правки сворачивания напоминаний остаются отдельно.
