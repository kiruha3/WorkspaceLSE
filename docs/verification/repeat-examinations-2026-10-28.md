# Классификация работы и повторные экспертизы — проверка 28.10.2026

## Реализовано

В карточке экспертизы появился раздел «Характер назначения и предыдущие заключения». Первичная / дополнительная / повторная работа не смешивается с комиссией или комплексом. Редактор сохраняет фактические реквизиты прошлых заключений, группу учреждения, сопоставимость исходных данных, подтверждение прежних выводов и документы. Полнота списка подтверждается отдельно. Неизвестные значения отличаются от «нет».

Данные: WorkClassification1:1Expertise, PreviousConclusion1:NWorkClassification, неизменяемые ClassificationRevision. Характер назначения остаётся в Expertise.appointment_nature. GET/POST `/api/v1/expertises/{id}/classification/` используют существующие области просмотра и work.update для открытых / closed.correct для закрытых работ. Новые права не назначаются. Обоснование и expected_version обязательны; ключ идемпотентности сохраняет попытку, права и документы проверяются также при повторе. Уточнение не меняет номер, фактический отдел, людей, результат, состояние или выдачу. При импорте ручная классификация защищена; активация истории не может молча заменить её.

В рабочем режиме15.1 добавлены H:N раздела4: повторных всего, три группы прежних учреждений и неподтверждение выводов по тем же исходным данным. Одна работа не умножается числом прежних заключений. Неполный список может подтвердить наличие группы, но не её отсутствие. Нет данных — прочерк и адресная ссылка на карточку, не предполагаемый ноль.

Backend возвращает75 версионированных пояснений всех действительно рассчитываемых граф разделов1–6. Знак вопроса в заголовке показывает смысл, единицу, дату отбора, поля источника, условия неизвестности и ограничения. Правила рабочего реестра и снимка различаются. Старый API без пояснения не получает придуманную клиентом формулу. Редакция правил входит в fingerprint выгрузки.
