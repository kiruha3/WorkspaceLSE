# Настройки папок документов — проверка 29.10.2026

## Реализованный срез

`/settings` объединяет доступные пользователю разделы. `/settings/storage`
позволяет открыть год, сохранить серверный путь и явно проверить чтение папки.
Настройки годов независимы. PUT не обращается к ресурсу; POST check запускает
отдельный процесс чтения с timeout 5 секунд, без рекурсии и изменения файлов.

Новое право `documents.storage.manage` назначается существующим редактором
ролей, только в области учреждения. Название роли/superuser прав не даёт.
Владелец отдельно разрешил добавить только это право в личную роль setup.
Существующие права, роли других людей и файлы не расширяются/не перемещаются.

## Решения реализации и оставшаяся работа

- Это настройка/проверка, не завершённая интеграция архива. Сопоставление
  папок, подтверждение связей с экспертизами, потоковое открытие файлов,
  OCR/Office — следующий срез; цена: ещё один этап для доступа к файлам.
- Переиспользован существующий feature checkout и Vite. Предшествовавшие
  изменения напоминаний сохранены отдельным checkpoint67d771b; цена: итоговая
  проверка охватывает оба согласованных этапа, а не только новый экран.
- .superpowers сохранён по предпочтению владельца; цена: остаются локальные
  игнорируемые журналы проверки.
- Настоящий зависший SMB не подключался: пример пути не выбран владельцем.
  Проверен bounded subprocess и штатный cleanup subprocess.run; цена:
  администратор ещё проверяет фактическую сеть своей кнопкой.
- Ревью было статическим, реальные команды и рабочая БД проверяются основным
  исполнителем; цена: независимый проверяющий не повторяет запуск тестов.
- Конкурентный подтверждённый импорт сохранён, вместо восстановления старого
  снимка сделаны новый дамп и контрольная точка; цена: первый снимок не может
  служить доказательством неизменности журнала за весь период работы.

Автоматических грантов в seed/migration нет. Рабочая БД не очищается, старые
документы не заменяются. Push/merge в master не выполняются.
