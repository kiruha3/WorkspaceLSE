# Обновление реестра: перечень принимаемых изменений

## Как пользоваться

На странице `http://127.0.0.1:5173/expertises` над фильтрами добавлены:

- **Обновить из таблицы** — читает настроенный Google-лист и открывает перечень изменений. Таблицу не изменяет.
- **Загрузить Excel/CSV** — выбирается файл, затем **Проверить файл**; открывается такой же перечень первого листа.
- **Источники и история** — прежний подробный импорт и сохранённые снимки остаются доступны.

В перечне для каждой изменённой регистрации показаны поля, значения БД и значения источника. Изначально ничего не выбрано. Можно отметить отдельные поля или выбрать все изменения без конфликтов. Ручное расхождение принимается только отдельным явным флажком. Новая экспертиза добавляется целиком, но только если отмечена её строка.

**Применить выбранное в БД** выполняет один атомарный пакет. Номера существующих экспертиз не меняются, дубликаты не создаются. Даты/состояние и подтверждённые количества проверяются в итоговом сочетании: несовместимые выбранные поля отклоняются с пояснением, невыбранные поля не исправляются незаметно.

Непринятые предложения можно принять позднее из того же снимка; повторное чтение таблицы их тоже сохраняет. Ручные расхождения не становятся неконфликтными после принятия другого поля. При потере ответа повторяется тот же пакет с прежним ключом. При устаревших данных нужно обновить перечень и выбрать поля заново.

**Обновить перечень** сравнивает текущую БД с тем же сохранённым снимком; для чтения новых правок Google нужно снова нажать обновление из реестра. Фильтры реестра не ограничивают импорт. Неоднозначного исполнителя или код можно уточнить через ссылку на подробное сопоставление. Продолженные в новом учёте работы и отдельные ручные сведения дела/классификации/сроков не перезаписываются; пояснение показано в строке.

Исторические связи с экспертами не создают новые штатные назначения, документы или допуски. Выгрузка реестра в XLSX по фильтрам в этот этап не входит и остаётся следующим шагом.

## Реализация и независимая проверка

- `1ec5004`: read-only review API и атомарный выбор отдельных полей поверх существующего импортёра.
- `259da39`: кнопки в реестре, файл/Google и страница `/imports/<batch>/review`.
- `a327cff`: единственный исправляющий проход после независимого ревью: принятие по полям, сохранение конфликтов, повторное частичное принятие, проверка итоговых значений и порядок блокировок повторно используемого материала комплекса.
- Схема БД, PHP, права пользователей, исходная таблица и прежние API не изменялись. Новых зависимостей нет.

Независимый reviewer `/root/journal_sync_final_review` проверил диапазон `9af329f..259da39` только чтением. Critical:0, Important:4, Minor:0, Declined:0. Все четыре Important воспроизведены тестами (включая настоящий PostgreSQL deadlock в изолированной тестовой БД) и исправлены одним проходом. Повторное ревью не выполнялось.
