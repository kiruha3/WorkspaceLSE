# Комплект выдачи и платность — проверка 28.10.2026

## Реализовано

Обычное заключение категории4 (КоАП) и акт экспертного исследования категории6 больше не отклоняются как неутверждённые комплекты. Нужны принятый итог, описание материалов, подписка и сопроводительное. Для1/5 сохраняется уведомление, для2/3 — счёт. У любой явно платной работы дополнительно обязателен счёт, в том числе у акта исследования; для платных1/5 нужны оба дополнительных документа, у2/3 счёт не дублируется. Оплата и наличие счёта не смешиваются.

Платность записывается по каждой работе в неизменной редакции комплекта. Можно сохранить «Не уточнено», но проверить и выдать такой комплект нельзя. Сумма/категория не подставляют значение. Оmitted/empty список при сохранении не стирает прежние сведения, явный null очищает их. Чужие/повторные работы и неверные поля отклоняются атомарно. Новая редакция, в том числе новая платность, делает прежнюю проверку устаревшей.

В Vue добавлены выбор платности по работам, просмотр и история редакций. Ошибки403/409 и поздний GET не стирают ввод; после потери ответа повторяется прежний пакет, версия и ключ. Новые маршруты, роли и grants не создавались. Изменение: `2c67452`, база среза: `aa99bf5`.

## Решения исполнителя и цена ошибки

В порядке принятия; повторяющиеся границы из независимого ревью сохранены явно.

| Решение | Причина и цена/ограничение |
|---|---|
| Платность в редакции комплекта, не в общем профиле дела | Подготавливающий комплект вводит её своим существующим правом; это не финансовый регистр, до комплекта такого факта нет |
| Unknown блокирует проверку/выдачу, но не черновик | Нельзя угадывать бесплатность; прежние неуточнённые комплекты потребуют ввода перед новой выдачей |
| Счёт2/3 сохранён даже при is_paid=False | Последнее уточнение добавляет правило, не отменяет прежнее; отмена потребует решения владельца |
| Неуказанные billing сохраняются, null очищает | Старый клиент не должен стирать факты; очистка требует явного null |
| СНДЗ/возврат/комиссия/частичная выдача не выводятся по аналогии | Обычный комплект4/6 не определяет остальные; общая цель ещё не завершена |
| Полный СНДЗ оставлен отдельно | Ответ владельца ожидается; выдача СНДЗ пока заблокирована |
| Возврат без исполнения оставлен отдельно | Возвращаемые материалы не обычное заключение; поток ещё требует комплекта |
| Число подписок комиссии оставлено отдельно | Один номер не доказывает одну подписку; комиссия пока заблокирована |
| Частичная выдача не добавлена | Не утверждена при продолжающейся работе; доступен только полный материал |
| Суммы/оплата/предоплата не включены в is_paid | Флаг — классификация выдачи; бухгалтерия требует другой модели |
| Автоматический счёт/реквизиты не созданы | Нет утверждённого шаблона; пока прикрепляется подготовленный документ |
| Массовая платность старых работ не проставлена | Нет подтверждённых фактов; существующее unknown остаётся unknown |
| Корректировка после выдачи не добавлена | Нельзя менять прошлую передачу тихо; нужна отдельная процедура |
| Полная приёмка ролей/официальный15.1 не приравнены к delta-review |100/318 проверяют этот срез, не ввод всего учреждения в эксплуатацию |
| Прежняя замена omitted description/note/items не переработана | Сохранение относится к новому billing; прочие поля по-прежнему передаются полной редакцией |
| Live-проверка не заменена обзором кода | Применение, перезапуск и сравнение ещё нужно доказать отдельно |
| Checkpoint/restore проверены исполнителем, не повторены ревьюером | Есть выполненные команды/хэши/результаты, но не независимое второе восстановление |
| Полный backend запускается после ревью | Профильный100/100 не заменяет общую проверку; до её результата срез не закрыт |

## Отложенные minor и оставшаяся общая цель

Одна новая работа, зарегистрированная другой сессией после открытия редактора, видна после GET, но её селектор платности появится после сохранения/повторного открытия формы. Версия комплекта от регистрации работы не меняется. Ввод и принятая попытка не теряются; неизвестное всё равно блокирует выдачу. Это Minor с рабочим обходом, не исправлявшийся в этом проходе.

Остаются полноценная сквозная приёмка всех ролей, неутверждённые комплекты/корректировки, источники файловURL/подключённые папки/офисное представление (нынешний Document поддерживает только бумажный оригинал/загрузку), production-профиль и устранение реальных пробелов для официального15.1. Существующие HTTP-проверки отдельных частей пути не объявляются одним полным ролевым E2E. PHP/Google и реальные рабочие факты не изменяются, push/merge не выполняются. Общая цель остаётся активной.
