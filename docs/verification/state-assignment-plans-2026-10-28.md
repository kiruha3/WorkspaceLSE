## Принятые решения и цена

1. Отдельный реестр, не словарь констант и не вывод из журнала: подтверждено294, но не распределение. Цена — специальности нужно явно заполнить, автоматически красивой разбивки не будет.
2. Один текущий план выбранного года для обоих источников: журнал неизменен, план изменяем. Цена — journal download теперь тоже связан с `expected_revision`, после правки плана требуется пересчёт.
3. Отдельное право учреждения без автоматической выдачи: название должности/роли не подменяет разрешение. Цена — существующие live-аккаунты пока только читают план, владельцу нужно утвердить редактора.
4. Один параметризованный SQL-снимок работ и плана с JSON-проекцией: предотвращает смешение редакций и работает на пустом реестре. Цена — дополнительный транспортный адаптер и его регрессионное покрытие.
5. Чистая проекция `plan_cells(snapshot,year,specialties)` вынесена отдельно: исключены циклический импорт и дублирование сопоставления. Цена — внутренний интерфейс отличается от сокращённого `plan_cells(snapshot)` в исходном плане.
6. Неизвестное сопоставление портит зависимые родители, но не подтверждённые листья/0. Цена — при изменении иерархии специальностей нужно сохранять порядок предков в сопоставлении и обновлять тесты.
7. Отложенные для ревью live-проверки не объявлялись пройденными заранее: backup/migration/browser/Excel проверены отдельно; положительная live-запись без нового разрешения не выполнялась. Цена — приёмка роли-редактора остаётся дальнейшим этапом.

Новых отложенных Minor в этом ревью нет. Ранее существующее предупреждение JS-бандла сохраняется:576.53kB/gzip158.61kB; разделение загрузки не входит в этот срез. Прежние отдельные замечания по карточкам/пояснениям/отображению истории не переобъявляются исправленными. Полная цель процесса остаётся активной.
