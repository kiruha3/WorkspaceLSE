# Проверка выдачи материалов

Общая цель остаётся незавершённой: полный рабочий путь, импорт и серверная форма 15.1 ещё требуют работы. Этап переписки принят отдельно на `cfd2b2e` с 244 серверными и 122 клиентскими тестами.

## Часть 1: подготовка комплекта

Первый тест до реализации падал с404 на чтении комплекта материала. После создания модуля прошли 22 проверки API: неполный черновик и история, ключи/версии/повторы, четыре известных категории, пять неутверждённых вариантов комплекта, бумажные оригиналы и загружаемые копии, недоступные документы, запрет удаления скрытых приложений, область всех работ материала и отдельная область записи, подбор документов, файловый доступ без права загрузки и сохранение отредактированного справочника.

При первой проверке моделей выявлено зарезервированное имя Django `check`: внутренние FK названы `package_check`, внешний контракт остаётся `check_id`. Это техническое уточнение, не изменение рабочего процесса.

Полный серверный прогон первой части: **266 из 266 за 352,09 с**, Django check без замечаний, расхождений моделей и миграций нет. Коммит `8c77aa1`. На работающей БД новые миграции пока не применялись, Django/Vite не перезапускались. Интерфейс и `/me.supported_modules` не рекламируют незавершённую выдачу.

## Принятые решения

- Продолжается существующий репозиторий и ветка `implementation`, без новой рабочей копии, push и merge. Исполнение здесь, одно итоговое независимое ревью всего среза; цена — обязательная общая проверка границ и браузерного пути.
- Уже выбранные Django/Vue не согласовываются заново. Владелец поручил продолжать; конкретные отсутствующие правила заданы отдельными неблокирующими вопросами. Если выбранное правило не подойдёт, оно корректируется до эксплуатационной приёмки.
- Пока поддерживается одна полная выдача материала, не неутверждённые частичные выдачи. Повторная выдача и исправление после неё потребуют отдельной процедуры.
- Неуточнённые комплекты 4/6, СНДЗ, возврата и комиссии явно блокируют готовность. Это не исключение их из общей цели; по ним ожидается подтверждение владельца.

## Часть 2: проверка и выдача

Перед реализацией 21 проверка команд, межролевого HTTP и учебного флага падала, 3 прежние проходили. Ещё 5 конкурентных сценариев падали на отсутствующей проверке комплекта. После реализации прошли 29 объединённых тестов, затем 49 расширенных проверок, включая реальные HTTP-сессии по категориям 1/2, гонки двух выдач, выдачи с регистрацией/корректировкой/новым файлом, старые успешные повторы, версии доказательства и область действия.

Дополнительно воспроизведена избыточная блокировка чтения файла собственной работы при ограниченном полном комплекте: ожидался200, был403. Исправлена именно файловая связь по общей спецификации: три права по видимой работе, без чтения чужого состава и без upload. Повторно прошли 27 проверок команд и файловых областей. Полный серверный прогон второй части: **296 из 296 за 437,43 с**, Django check без замечаний, дрейфа миграций нет; коммит `000b4c9`.

Независимая Vue-подзадача завершила реализацию в `frontend/`, не меняя backend/данные/серверы. Основной исполнитель повторил её полный прогон: **147 из 147**, TypeScript и production build без ошибок. Ограничение общего создания метаданных документа при полностью потерянном первом ответе записано явно, а не объявлено решённым проверками повторной загрузки файла.

## Часть 3: настоящий встроенный браузер

Новые миграции применены, исходные способы выдачи добавлены без сброса справочника. Только учебным ролям явно добавлены новые права через `workflow-demo --enable-issuance`. Перезапущен единственный Django; один Vite на `0.0.0.0:5173` сохранён. Пароли и данные подключения не публиковались.

Через обычные формы под `demo.clerk` подготовлен комплект ДЕМО `900001/3-1-26`: описание материалов, новая подписка с тестовым JPEG, бумажные сопроводительное и уведомление. Проверка закрепила редакцию 2, принятую версию 1 заключения при существующей более поздней версии 2 и версии приложений. Затем отдельно записана учебная выдача от 28.10.2026 нарочно с учебным получателем, основанием и бумажным подтверждением. Комплект `f738823c-1e6c-4069-a151-ca929c178110` получил состояние «Выдано», редактирование и повторная выдача исчезли. Это не реальная передача судебных материалов.

Отрицательный пример `900003/3-1-26` зарегистрирован через приёмку и оставлен незавершённым. Его комплект `262db812-5b23-4b44-be15-83ad49e2b34b` показывает «Работа ещё не завершена», проверка и выдача недоступны; окончание не выдумывалось. Под `demo.expert2` своя завершённая работа показывает дату выдачи и доступный комплект, но кнопок подготовки, проверки и выдачи нет. В журнале отбор «Выдано» за 28.10.2026 возвращает ровно положительный пример, не незавершённый.

Снимки находятся в игнорируемой `.runtime/`: `issuance-issued-browser.png`, `issuance-pending-blocked-browser.png`, `issuance-expert-readonly-browser.png`, `issuance-registry-browser.png`. Детальные учебные идентификаторы — `issuance-browser-qa.md`. Настоящий журнал, Excel, Google и прежний PHP не менялись.
