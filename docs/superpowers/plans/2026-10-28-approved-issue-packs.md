## Review Focus

- Old null subscription rows, including historical/read-only/issued revisions, are readable and not silently attributed to a document author; new actor assignment is an explicit new revision.
- A single subscription file, duplicate participant, foreign/ended participant or a null commission flag cannot falsely satisfy a two-expert commission, including conflicting concurrent requests.
- A GET that introduces a new work without changing package.version must offer a billing row without replacing edited values or the immutable lost-response packet.
- Ordinary/returned/SNДЗ/commission combinations preserve invoice rules and accepted-version null/V1 pins; internal return evidence must not be represented as a required outgoing conclusion.
- New Vue must remain usable against the old server during local staged rollout: absent new DTO fields and omitted null employee payload must not break ordinary issue forms.
