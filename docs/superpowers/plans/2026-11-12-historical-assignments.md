# Исполнители из исторических соответствий

Разовая операция в настройках импорта, отдельно от обновления журнала.
Предпросмотр показывает сохранённых исторических участников и возможность
создать текущие назначения. Применение — только для отмеченных работ после
подтверждения, с правами импорта и назначения в отделе работы.

Выбран отдельный пакетный перенос: обычное назначение требует полного
подтверждения исторического учёта, а автоматический перенос при обновлении
источника мог бы затереть последующее перепоручение.

Переносятся только открытые, не выданные работы без истории назначений.
Используются явно сопоставленные участники, без угадывания ФИО. Нужна
полученная специальность, обучение не допускается. Неизвестный признак
комиссии сохраняется; при дальнейшем подтверждении учёта состав проверяется.
Номера, отделы, состояния, исходный текст и исторические даты не меняются.
Дата назначения — момент применения; происхождение сохраняется в снимке
назначения и аудите. Полное подтверждение учёта остаётся отдельным действием.

План: тесты API → предпросмотр/пакетная команда с блокировками и проверкой
устаревания → совместимость подтверждения истории → страница настроек и
проверки выбора/повтора → регрессия назначения и активации, сборка.
Миграция схемы не требуется. Рабочую БД автоматически не изменять.
