# Выгрузка реестра в журнал XLSX

Согласованный результат: кнопка «Скачать Excel» выгружает всю доступную выборку по применённым фильтрам реестра, без пагинации. Используется существующее право `expertise.export` в пересечении с `expertise.view`; права и бизнес-данные не меняются.

1. Закрепить тестами отсутствующий API: 28 исходных колонок, трёхстрочная шапка, актуальные значения БД, нули/пустоты, текстовые номера, формулы как текст, области доступа и фильтры.
2. Вынести общий фильтр реестра; добавить отдельный XLSX API и построитель на существующем openpyxl.
3. Добавить кнопку и проверку прав в реестр; использовать применённые URL-фильтры и существующий загрузчик с отдельным запасным именем файла.
4. Проверить целевые backend/frontend тесты, существующий отчётный загрузчик и сборку; передать основному исполнителю для полного общего backend прогона.

Источником истины служат текущие модели. Исходная строка используется только для A, Y, AB, для которых нет нормализованных полей. Структура и размеры первой вкладки сверены с локальным эталоном `в АИС - 2026 новая лсэ (1).xlsx`; сам эталон и персональные данные в репозиторий не копируются.

Полная таблица соответствия и ограничения: [docs/api-journal-export.md](../../api-journal-export.md).
