# Карточка экспертизы — вариант А

Владелец выбрал первый макет с вкладками и поручил сделать контрольный коммит, затем реализовать. Контрольная точка: `100ee76`. Изменяется только фронтенд текущей карточки, не API, права, БД или правила учёта.

## Границы и подход

Из рассмотренных вариантов выбраны верхняя сводка и горизонтальные вкладки; альтернативная навигация слева отклонена владельцем. Сохраняются текущие компоненты форм, их запросы, серверные allowed_actions/can_edit, документы, истории и все существующие поля. Новые поля и бизнес-команды запрещены. Вкладки являются только локальной навигацией.

Один заголовок с номером/состоянием, прежние возврат в реестр, обновление и переход в архив. Обзор: факты регистрации и краткие сведения результата, существующие исполнитель/даты. Для неоперационной исторической работы источники исполнителя, окончания и выдачи явно названы историческими; отсутствие нативного назначения не отменяет исторического исполнителя. Для новой работы не выводить фиктивную выдачу из даты окончания или даты черновика результата. Ноль отличать от неизвестного.

Вкладки: Обзор; Дело (основание, сведения дела, классификация); Исполнители (назначения, история, переход исторической работы в новый учёт); Производство и сроки (включая отчётные причины); Результат (исторические уточнения и текущий результат); Переписка/Выдача только при прежних условиях доступности; История исходного журнала только для исторической работы. Исходные подробные блоки не удаляются.

Панели сохраняются смонтированными при переключении вкладок: незавершённые формы/попытки команд не теряются; переход между работами по-прежнему защищён dirty guard. При смене UUID сброс вкладки на обзор и отсутствие старых сведений во время загрузки. Вкладки доступны с клавиатуры, имеют tablist/tab/tabpanel, aria-selected, roving tabindex, Home/End/стрелки. При отзыве доступности выбранного раздела возврат к обзору.

Стили ограничены карточкой, шрифты/контраст усилены без редизайна других страниц. На узком экране сводка/колонки складываются, вкладки прокручиваются внутри своей полосы, не расширяя страницу.

## Проверка

Компонентные тесты реальной страницы: навигация, сохранение черновика, источники/нулевые значения, отсутствие лишних действий/POST при переключении, сброс при смене работы, права и клавиатура. Старые тесты форм остаются. Полный frontend test, typecheck/build; браузерная проверка реальной карточки без записи данных. Проверка кода свежим рецензентом. Бэкенд/миграции не меняются.

Предварительный полный frontend baseline: 344 passed, 2 failed из 346. Оба падения — существующие RED `CaseDetailsPanel.test.ts` о ещё не реализованном флаге; их нельзя прятать, удалять или реализовывать бизнес-изменение в этом срезе. Итог должен иметь ноль новых падений, исходные два указываются отдельно.
