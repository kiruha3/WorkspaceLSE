# Справка по значку вопроса

Пользователь просит убрать пояснения из постоянно видимого текста и показывать их по «?» при наведении. Это уточнение компактной карточки, без изменения полей и бизнес-процесса.

Используем один Vue-компонент HelpTip: вопрос рядом с заголовком/полем, всплывающий текст при наведении или фокусе, закрепление нажатием для сенсорного экрана, Escape и нажатие снаружи закрывают. Текст доступен через aria-describedby, окно помещается в экран и не обрезается карточкой. Нативный title не подходит для управления клавиатурой и длинного текста; отдельные модальные окна нарушают запрос о наведении.

Переносим справочные правила карточки и её форм: исполнители, дело, классификация, сроки, результат, исторические сведения, документы и выдача. Фактические даты, значения, причины, отсутствие документов, текущие ошибки/конфликты/блокировки и явное подтверждение возврата остаются видимыми. Поля, команды, права, обязательность документов и схема БД не меняются. Две существующие правки напоминаний не включаем в коммит. Без push и без сохранения реальной экспертизы при проверке.
