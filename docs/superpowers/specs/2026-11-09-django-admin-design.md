# Служебная Django-админка

Основание: владелец попросил подключить стандартную админку после обсуждения её служебного назначения. Реализуем в текущем проекте без отдельного приложения и без повторной разработки рабочих команд.

- `/admin/` доступен через тот же веб-порт 5173; Vite передаёт также административную статику в Django.
- Существующие сотрудники, роли и все рабочие модели доступны для поиска и просмотра. Для рабочих изменений есть переходы в соответствующие разделы Vue. Прямые изменения состояний и удаление событий не предоставляются.
- Справочники редактируются через существующие команды с проверкой права `references.manage`, версий и журналированием. Код существующего значения не меняется; вместо удаления есть деактивация.
- Учётные записи обслуживаются через стандартный UserAdmin. Создание, изменение и смена пароля пишутся в AuditEvent без паролей и их хешей. Сотрудник и роли АИС оформляются существующим интерфейсом.
- Вход в служебную панель разрешён активному Django-суперпользователю с `is_staff`. Это отдельный доступ от ролей АИС; он не расширяет права API. Команда `django_admin_access <username>` явно включает его существующей учётке без смены пароля и назначения ролей. `--revoke` отзывает.
- Bootstrap не повышает права автоматически. Для текущего локального стенда доступ включаем `setup`, как администратору системы. Для удалённой установки даём точные команды обновления.

Альтернативы: обычный CRUD для всех моделей обходит команды и историю; полностью отдельная админка повторяет существующий Vue-интерфейс. Выбран стандартный Django Admin с адаптерами справочников и просмотром рабочих данных.

Проверка: полноценные запросы HTML, доступ обычных пользователей, справочники/версии/журнал, запрет записи рабочих событий, аудит смены пароля, включение/отзыв доступа, миграции, статические ресурсы и общий набор тестов.

## Русские подписи

По дополнительному запросу владельца локализуются поля, заголовки списков и карточек, фильтры и технические варианты выбора. Связанные записи показывают ФИО, регистрационный номер или название с переходом к записи. Отображение реализовано в `apps/common/admin_labels.py` и `admin_localization.py`: словарь подписей и адаптер ModelAdmin. Переведённые копии описаний фильтров и шаблонного контекста не изменяют `_meta` моделей. Имена полей БД, значения API и исходные JSON остаются прежними; миграций нет. Сортировка, фильтрация, неизменяемые поля, команды справочников и их проверка версий сохраняются.
