# Серверный предварительный отчёт 15.1

Владелец попросил закончить видимую выгрузку, отложив рисование схем. Сохраняем уже согласованные Vue/Django и правила старого расчёта `web-vue/src/workplace/form151.ts`, не трогаем PHP, Google и бизнес-записи.

## Результат этого шага

- `/reports` в новой АИС: снимок первого листа, год, месяц (накопительно с января), явное подтверждение полноты журнала для остатков, серверный предпросмотр и скачивание XLSX.
- Источник — неизменяемые `ImportBatch`/`ImportRow`, а НЕ шесть тестовых рабочих экспертиз. Не смешивать источник с рабочей БД и не считать это переносом записей.
- Django рассчитывает разделы 1–6. Разделы 7–8, неподтверждённые причины, повторность, 3214-р, разбивка плана не заполняются. Неизвестное не заменяется нулём. Статус всегда «Предварительный».
- Каждая рассчитанная ячейка содержит номера физических строк источника. Пробелы сгруппированы и показаны в вебе. В файле пометка предварительности на титуле; исходный бланк и состав девяти листов сохранены, чужие примеры не остаются в данных.
- Общий план 2026 — 294; госзадание категории 1 и 5. Работы — отдельные текущие номера, а не ФИО. Комиссионная один номер, комплексная отдельные номера. Старый номер в скобках не задаёт дату поступления в новую организацию.
- Даты поступления и конца периода определяют остаток. Для предварительного исторического отчёта без исполнения применяется ранее согласованное правило старого расчёта: P или однозначная фактическая отметка возврата/выдачи W/X; пустые P/W/X — ожидание выдачи. Это не создаёт дату решения о возврате в рабочей БД.
- Противоречия номеров/дат/результатов и дубли не замалчиваются; точный дубликат текущего номера останавливает расчёт. Даты после среза не считаются завершениями.
- Только институциональные `imports.results.view` + `reports.form151.run`; для XLSX дополнительно `reports.form151.download`. Отчёт по смешанному источнику не выдаётся под правами одного отдела. Отзыв прав проверяется на каждом запросе.
- В этой итерации нет записи отчётных запусков и нет официальной сдачи. Источник идентифицирован UUID/hash/датой, версия расчёта фиксирована. Новые зависимости и миграции не нужны.

## API

GET `/api/v1/reports/form151/?batch_id=<uuid>&year=2026&month=10&opening_balances_complete=false` возвращает период, метаданные источника, ячейки, пробелы, покрытие разделов, относительную ссылку на тот же XLSX. Неизвестные параметры/невалидный период отклоняются.

GET `/api/v1/reports/form151/xlsx/` с теми же параметрами возвращает файл бланка с серверными цифрами. Данные одинаковы с предпросмотром; HTTP no-store. Скачивание не требует внешней сети.
