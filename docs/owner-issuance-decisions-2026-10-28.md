# Уточнённые правила выдачи — 28.10.2026

Источник — прямые ответы владельца в чате. Это требования для следующего среза, а не заявление об уже выполненной реализации.

| Случай | Подтверждённый состав |
| --- | --- |
| Полный СНДЗ | Подписка, сопроводительное письмо, сообщение о невозможности дать заключение (СНДЗ). |
| Комиссионная экспертиза | Отдельный документ подписки на каждого эксперта. Один общий документ не заменяет отдельные подписки. |
| Возврат без исполнения | Возвращаемые материалы/документы и сопроводительное письмо. Подписка для этого случая не указана. |

Ранее подтверждённое требование счёта для любой платной работы сохраняется; счёт не равен подтверждению оплаты. Ранее установленное правило счёта для гражданских/арбитражных работ этим ответом не отменено. Обычный комплект с заключением не следует автоматически применять к полному СНДЗ: уведомление в новом перечне СНДЗ не названо.

При реализации нужно разделить внутреннее основание решения о возврате и состав передаваемого комплекта: отсутствие отдельного решения среди выдаваемых приложений не отменяет сохранённую историю завершения без исполнения.

Текущее ограничение прежней реализации: эти сценарии ещё могут показывать `policy_unconfirmed`; отдельной связи подписки с участником комиссии пока нет. Предстоят серверные требования/проверки, DTO и формы, регрессионные тесты и фактический прогон. Проверка обычного заключения в текущем сквозном сценарии не доказывает готовность этих новых вариантов.
