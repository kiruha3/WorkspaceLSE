# Уточнения владельца по отчёту15.1 — 28.10.2026

## Причина полного СНДЗ в текущем журнале

Прямой ответ владельца на перечень четырёх СНДЗ с отсутствующей причиной: «науки и техники это по всем сндз».

В контексте текущего журнала это подтверждает причину «современный уровень развития науки и техники не позволяет ответить на поставленные вопросы» для:

- 177/1-5-26;
- 213/1-1-26;
- 319/4-1-26;
- 325/4-5-26.

Соответствие существующему справочнику/расчёту: `science_cannot_answer`, раздел1, официальная графа6, Excel `I` (итог `I108`, специальность18.1 `I65`). Ожидаемый вклад этих четырёх регистраций —4. Это фактическое уточнение владельца, не вывод из самого термина СНДЗ и не нормативное заключение.

Не вводится автоматическая причина для всех будущих СНДЗ. Статистика вопросов Q/R/S/T и распределение отдельных нерешённых вопросов не меняются этим ответом.

## Признак3214-р и самовольное строение

Следующее прямое уточнение владельца: «3214-р. только у16.1 16.2 - видно будет видно их по флагу самовольное строение».

Правило для реализации: работа включается в графу3214-р только при специальности16.1 или16.2 **и** явной отметке «Самовольное строение». Сама специальность недостаточна; остальные специальности не включаются. Не определять признак по случайным словам описания и не включать автоматически все строительные экспертизы.

Отметка должна быть видна в карточке и объяснении отчётной графы, с возможностью отбора соответствующих работ. Её связь с существующим `decree3214` требуется реализовать согласованно, не сохраняя два независимых противоречащих флага. Это уточнение ещё не означает изменение кода, расстановку признаков в исторических карточках или выполненный пересчёт. Данные конкретных работ не выдумываются.

Владелец уточнил место ввода: «при регистрации указывать или при редактировании». Предусмотреть оба пути: необязательная отметка при регистрации работы16.1/16.2 и изменение того же признака в карточке по существующим правам редактирования, с историей. Не требовать повторной регистрации ради исправления отметки. Для остальных специальностей признак не предлагается и работа в графу3214-р не включается. Пустая/невыбранная отметка не должна блокировать регистрацию или предварительный отчёт. Действующая модель сейчас требует отдельный документ и пояснение для `decree3214=true`; до реализации обычного флага это ограничение нужно пересмотреть явно, а не объявлять интерфейс уже готовым.

## Состояние применения

### Обновление29.10.2026

Флаг «Самовольное строение» реализован при регистрации и редактировании16.1/16.2, без обязательного дополнительного документа. Рабочая миграция и расчёт применены; [доказательства проверки](verification/construction-flag-2026-10-28.md). Исторические отметки автоматически не расставлялись.

По новому прямому ответу «Дай ему все права» setup выданы все61права текущего каталога АИС, включая корректировку завершённых работ; [проверка доступа](verification/setup-full-access-2026-10-29.md). Поэтому описанный ниже прежний блокер доступа устранён. Сами четыре причины СНДЗ **ещё не записаны** — это следующий последовательный шаг.

### Проверка до нового разрешения владельца

Существующие четыре карточки проверены через HTTP: исторические, завершены, результат `sndz`, версия1, причинаnull. Данные **ещё не изменены**. У имеющихся рабочих пользователей нет подходящего права `expertise.closed.correct` на эти реальные карточки; у учебного expert2 есть только своё право на его работы. Права не расширялись, прямого обхода сервисной корректировки/SQL-изменений не выполнялось. При применении нужны штатная историческая корректировка с основанием из этого ответа, сохранением остальных полей/истории и повторная сверка отчёта. Ограничение записи не должно становиться новым ограничением просмотра или предварительной выгрузки отчёта.
