# Проверка переписки и контроля ответов

Проверяется модуль самостоятельных и связанных писем в Django и Vue. Общая цель проекта остаётся незавершённой: после этого среза нужны выдача, импорт, оставшиеся документы и сверка 15.1.

## Автоматические проверки

Первый серверный этап: 212 тестов прошли за 245,95 с, Django check без замечаний, расхождений моделей и миграций нет. Коммит `457ffe5` содержит черновики, области доступа, документы и справочники.

Второй этап: первоначально 21 новый тест падал из-за отсутствующих команд и флага, 2 старых теста проходили. Затем прошли 44 объединённых проверки и ещё 22 проверки команд и обоих направлений HTTP-переписки. Полный серверный прогон: 239 из 239 за 325,79 с, Django check без замечаний, расхождений моделей и миграций нет. Коммит `2032817` содержит регистрацию, отправку, получение, доставку, ответы и контроль.

Регрессия производительности: первоначально журнал из 25 самостоятельных писем выполнял 165 запросов. Причина — повторное чтение текущего сотрудника для каждого действия в каждой строке. Проекция использует свежие права, вычисленные для запроса, без постоянного кэша прав. Тест ограничивает число запросов для такой страницы значением менее 90.

Фронтенд: 119 из 119 тестов, отдельная проверка TypeScript и production build прошли. Добавлено 23 теста переписки и проверка маршрута; прежние 95 сохранены. Постоянно работает один Vite на `0.0.0.0:5173`, Django — на loopback `8000`, PostgreSQL — на `55432`. Дополнительные постоянные серверы не запускались.

## Проверка через браузер

Миграции применены, Django перезапущен без дополнительного экземпляра, учебные права переписки включены явным флагом. Созданы два журнала с названиями «ДЕМО · входящая переписка» и «ДЕМО · исходящая переписка». Проверка выполняется только на явно учебных профилях и письмах; результаты двух направлений и адреса карточек будут внесены после прохождения. Автоматические HTTP-тесты не подменяют визуальную проверку.

Оба направления пройдены через формы встроенного браузера под `demo.clerk`:

1. Входящий [ДЕМО-ВХ-001](http://127.0.0.1:5173/letters/48ef5066-8ac9-45a8-ac68-3c765bcf70d3) связан с учебной экспертизой 900001/3-1-26. Получение оставлено неизвестным, регистрация его не подставила. Открыт контроль без срока. Создан [завершающий исходящий ответ](http://127.0.0.1:5173/letters/d95dab55-8483-4a30-bcdf-322f072562d4), через системный выбор файла загружено учебное изображение `result-replay-green.jpg`. Веб показывает файл, регистрация ДЕМО-ИСХ-001 и последующая отправка сохраняют версию 1. После отправки контроль родителя оставался открытым, затем явно закрыт с выбором этого ответа. Доставка при этом не выдумана.
2. Исходящий [ДЕМО-ИСХ-002](http://127.0.0.1:5173/letters/a0ed7002-c91d-454e-ad27-210d4ffe5c3e) зарегистрирован, отдельно записана отправка и открыт контроль с явно учебным сроком 05.11.2026. Через «Создать ответ» зарегистрированы ДЕМО-ВХ-002 (частичный), ДЕМО-ВХ-003 (дополнительный), ДЕМО-ВХ-004 (завершающий). После первых двух контроль проверен как открытый. У завершающего дата получения первоначально неизвестна; затем она подтверждена отдельным событием. Все три ответа сохранены в родителе, контроль всё ещё открыт. Только последующая команда закрыла его по основанию «Завершающий ответ получен».

Два локальных снимка: `.runtime/correspondence-incoming-closed.png`, `.runtime/correspondence-outgoing-closed.png`. Подробные шаги и UUID учебных файлов сохранены в игнорируемом `.runtime/correspondence-browser-qa.md`; пароли в доказательства не включены.

## Принятые решения

- Работа продолжается в существующей ветке `implementation`, без push, merge и новой рабочей копии. Backend реализуется здесь, Vue подготовлен независимой подзадачей; итоговый срез получает одно отдельное ревью. Цена такого разделения — обязательная проверка общего API и браузерных сценариев.
- На неизменённом коде прежнего среза не повторялся исходный прогон 195/95: использовано подтверждение соответствующего коммита, затем каждый новый серверный этап проверяется полным набором тестов. Возможное изменение окружения обнаруживается в этих прогонах.
- Номер письма пока ручной, в настраиваемом журнале и году. Единый журнал или отдельные журналы отделов владелец ещё не уточнил. Учебные журналы не устанавливают регламент учреждения; перед реальным учётом нужна правильная конфигурация.
- Регистрация замораживает содержание, а поздние файлы и факты ведутся отдельно. Ошибка зарегистрированных реквизитов требует будущей явной корректировки; обычное редактирование её не скроет.
- Корреспонденты и адресаты пока типизированные имена, адреса и email, без вымышленных реквизитов организаций. Позднее общие справочники добавят связи рядом с сохранёнными фактами; до этого нет автоматического устранения дублей организаций.
- Vue требует признак `correspondence` от `/me`. Старый сервер без признака не показывает неработающие формы. Признак нельзя выпускать до готовности команд и миграций.
- Контроль впервые открывается после регистрации. Известному сроку нужны дата и основание, без автоматического нормативного календаря. Изменение срока записывается текущей датой; дорегистрационный контроль или исправление исторической даты потребуют отдельного расширения.

## Оставшаяся работа

Итоговое независимое ревью и фиксация его результатов ещё не завершены. Это не подтверждение готовности всего учреждения к рабочей эксплуатации. Изменения старого PHP, виртуальной машины, исходных таблиц и реальных учётных записей не требуются.
