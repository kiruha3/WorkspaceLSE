## Незначительные замечания — отложены

1. Форма предлагает постановку на контроль до регистрации и изменение срока закрытого контроля. Сервер отклоняет эти команды без изменений. Нужно точнее скрывать невозможные действия; цена отсрочки — лишнее заполнение формы.
2. У читателя без прав подготовки/назначения пустой выбор отдела и ответственного в фильтрах, хотя письма доступны. Нужны отдельные минимальные варианты фильтров из видимой переписки, без расширения вариантов записи. Пока можно искать текстом; фильтры менее удобны.
3. Время подкрепления файла выводится как исходный UTC, а не как остальные даты учреждения. У границы суток день может отличаться. Нужен единый формат Asia/Krasnoyarsk; сохранённый момент не меняется.
4. Email адресата длиннее 254, но не длиннее допустимых валидатором 320 символов, может дать серверную ошибку вместо ошибки поля. Транзакция откатывается, частичная редакция не остаётся. Нужна явная граница длины поля; пока редкий некорректный ввод требует исправления адреса.

## Границы, на которые ревью не выносило заключение

Каждый пункт — решение сохранить обозначенную границу, а не считать функциональность готовой.

| Решение | Что получает пользователь и почему | Цена, если этого недостаточно |
| --- | --- | --- |
| Реальная почта, ЭДО и почтовая доставка не реализуются этим срезом | Ручная фиксация совершённых фактов, без внешних отправок | Интеграции потребуют отдельной реализации и проверки |
| Нумерация ручная, окончательные журналы не выдумываются | Настраиваемые журналы и защита от дублей в журнале/году | До реального учёта нужно определить структуру журналов; автоматической выдачи номера нет |
| Зарегистрированные реквизиты, удаление/открепление и отмена подтверждений не переписываются | Исторические факты заморожены | Ошибку нельзя исправить до отдельной процедуры корректировки |
| Организации/контакты пока текстовые факты | Переписка работает без вымышленных реквизитов | Общий справочник и устранение дублей остаются следующей работой |
| Печать, офисный предпросмотр, URL и папки остаются следующими частями | Файлы поддержанных форматов прикрепляются и показываются в вебе | Нельзя считать весь файловый/печатный контур готовым |
| Выдача, импорт, 15.1 и эксплуатационная приёмка не подтверждены перепиской | Принят только отдельный рабочий срез | Общая цель остаётся активной, полного производственного запуска пока нет |
| Внешнее сканирование и инфраструктурное усиление не выполняются | Соблюдён исключённый пользователем объём | Ревью не является внешней инфраструктурной аттестацией |
| Производительность подтверждена только проверенной регрессией журнала | Есть ограничение числа запросов для страницы из 25 писем | Большие объёмы и нагрузку нужно проверить перед производственным запуском |
| Уже показанные до отзыва прав сведения не стираются с экрана удалённо | Новое чтение и повтор команды перепроверяют нынешний доступ | Старый открытый экран не отзовёт уже прочитанные сведения; при необходимости нужен отдельный механизм |
| Контроль до регистрации и историческая корректировка сроков не добавляются | Известные даты и основания записываются явно; неизвестные остаются пустыми | Иные процедуры потребуют расширения, а не выдуманных дат |
| Прогресс ответа отделён от права закрыть контроль | Зарегистрированный завершающий ответ виден как прогресс, но закрытие требует получения/отправки | Пользователь должен отдельно подтвердить соответствующий факт и закрыть контроль |
| Бумажный документ допустим без электронного файла | Учёт не изображает отсутствующий скан существующим | Предпросмотр появится только после фактической загрузки файла |
